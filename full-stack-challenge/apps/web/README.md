# Dynamox Full-Stack Challenge — Web

Frontend of the application, built with React 18 + TypeScript + Vite + Redux Toolkit + Material UI 5.

Full project documentation (setup, features, bonus, assumptions, credentials): see the [main README](../README.md).

## Commands for this folder

```bash
npm run dev       # starts the development server (http://localhost:5173)
npm test          # runs the unit tests (Vitest + Testing Library)
npm run build     # production build
npx cypress open  # opens Cypress in interactive mode
npx cypress run   # runs the full e2e suite in headless mode
